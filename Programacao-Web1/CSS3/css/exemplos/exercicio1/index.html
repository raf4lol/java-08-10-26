HTML

HTML é a linguagem de marcação padrão usada para criar e estruturar páginas e conteúdos na web.

O que é HTML?

  • Significa HyperText Markup Language (Linguagem de Marcação de HiperTexto).
  • Não é uma linguagem de programação, mas sim uma linguagem de marcação.
  • Usa tags (rótulos) para organizar e definir cada elemento de uma página, como textos, títulos, imagens e links.
  • Funciona como o esqueleto ou a estrutura base de um site.

CSS3

  • O CSS (Cascading Style Sheets), ou Folha de Estilo em Cascata, é a linguagem utilizada para definir a apresentação visual de páginas web. Enquanto o HTML funciona como o "esqueleto" do site (estruturando os textos, títulos e imagens), o CSS atua como as "roupas e a maquiagem", controlando aspectos como cores, fontes, espaçamentos, layouts e animações. W3C (World Wide Web Consortium) em 1996, o principal objetivo do CSS é separar o conteúdo do design. Essa separação torna o código mais limpo, facilita a manutenção de sites grandes e melhora o tempo de carregamento das páginas.
